# ПРАВОСМОЛ — премиальный сайт юридической фирмы

Многостраничный сайт юридической фирмы «ПРАВОСМОЛ» (pravo-smol.ru) в тёмной кинематографичной
эстетике: графит, шампанское золото, молочные секции, Cormorant Garamond + Manrope.

## Стек

- **React 18 + TypeScript** (Vite)
- **Tailwind CSS 3** (кастомная палитра в `tailwind.config.js`)
- **Framer Motion** (прелоадер, построчные заголовки, параллакс, счётчики, переходы страниц)
- **react-router-dom 6** (главная + 7 страниц направлений + правовая информация)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Структура

```
src/
  lib/data.ts          # весь контент: 7 направлений, команда, цифры, отзывы, контакты
  lib/seo.ts           # title/description для каждой страницы
  components/          # прелоадер, курсор, частицы, навигация, футер, форма, motion-примитивы
  pages/Home.tsx       # hero с Фемидой + 9 секций
  pages/Practice.tsx   # шаблон страницы направления (дело № 01–07)
  pages/Legal.tsx      # политика конфиденциальности
public/images/         # фотографии (Wikimedia Commons, атрибуции в NOTICE.md)
```
